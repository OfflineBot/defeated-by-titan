wait 1.5                # world, camera, meshes and the render pipelines come up (90 ticks)

# ---- ACT 1 · get him onto his legs with a rope spot in front of him --------------------------
# The same clear ground `scripts/game-full.txt` ACT 1 starts on: the market hall covers
# x -47..-15, this does not, and a hook fired from here really bites. `look 180 66.6` puts the
# anchor **up and behind him at yaw 180 = +Z**, so `S` walks him straight away from it.
# ⚠️ **`S` points at -Z from here and that is deliberate**: measured 2026-08-26, the +Z side of
# this spot is blocked (a walk into it reads 0.915 m/s instead of 6.000), so a run that walked
# the other way would report the wall and call it the rope.
look 180 66.6
warp 45 0 -43
wait 0.5                # the warp takes effect one tick later than it is written
mark f176-standing
assert speed < 7        # on his LEGS, not still falling: this is the state the acts start from
assert height < 1.0     # and ON the ground (y ~ 0.3) — ACT 5's yank is measured against this

# ---- ACT 2 · THE CONTROL, FIRST · the same key with nothing holding him ----------------------
# 🔴 Without this, ACT 3's number is worthless — a player who is simply stuck also reads slow.
# It runs BEFORE any rope exists (re-derived for §5E-b: the old script put it last, but now a
# release drops the player out of a live swing and the landing spot is nobody's pin).
# ⚠️ 1.2 s of key for 1.0 s of measurement: `ground_step` stops a walk in the SAME tick the
# key ends, and a first version measured a player who had already stopped (§6 rule 5).
key S 1.2
wait 1.0
mark f176-the-same-second-of-s-with-no-rope
assert rope < 1
assert speed > 4.0      # if this is not near run speed, ACT 3 would measure a player who
                        # cannot walk at all
wait 0.4                # the key lapses; the walk stops the same tick
look 180 66.6
warp 45 0 -43           # back to the pinned stance (warp zeroes the velocity)
wait 0.5

# ---- ACT 3 · §5D rule 4 · S DOWN BEFORE THE BITE ⇒ planted ----------------------------------
# ⚠️ **The order is the act.** Under §5E-b a bite with no key pulls IMMEDIATELY — the old
# `hook, wait 0.5, key S` shape hands the free pull half a second of drag before the cancel
# arrives. S goes down first (one tick ahead of the trigger), so there is no tick in which the
# pull owns him, which is `tests/player.rs::f176_s_on_the_ground_keeps_the_legs_*` in game form.
# ⚠️ Durations: S covers 0..2.2 s, the trigger 0..4.6 s. ACT 3 measures at +1.5 s (S and rope
# both live); ACT 4 begins after S lapses and while the rope holds.
key S 2.2
hook right 4.6
wait 1.5
mark f176-a-second-of-s-on-the-rope
# ⚠️ **The band is 6.5 and not 2**: the stand is a SWING, measured per tick 2026-09-01
# (`tests/vector_rope.rs::probe_ground_walk_on_a_rope`) — S injects the walk (6.0 m/s) against
# the taut sphere and |v| cycles 0.5..5.9 while the anchor distance holds to three decimals.
# What the band separates is the HAUL: the pre-rule-4 behaviour read **7.63 m/s** through this
# stance, 1.1 m/s above the band. An escape WITH the rope is the 288-cell matrix's to forbid.
assert speed < 6.5
assert rope > 0         # and the rope is still there: the cancel releases nothing (§3F)

# ---- ACT 4 · §3F · „zur seite gehen" ON A TAUT ROPE, AND IT IS A SWING -----------------------
# Sideways on a sphere centred 34 m over your head is upwards; the joint holds the radius
# (288-cell matrix), which is „aber NICHT das seil verlängern!!" met exactly. Since §5D the
# lateral also SCALES the pull (rule 3, `pull_scale`): what hauls him during this act is
# `drive_idle_speed_m_s` x `drive_steer_pull_fraction`, not the full winch. S lapsed 0.1 s
# before A lands — six ticks of full free pull, and that is §5E-b working, not slack.
#
# ⚠️ **ONE ceiling, derived from `game.ron`, not from a measurement**: `rope_drive` chases at
# most `vector.drive_speed_m_s` = 52 and the pull is a FLOOR under the closing speed
# (property 1 — it never adds to a faster approach), so 55 is this mechanism's ceiling with
# 3 m/s of swing margin. A `FIND-182`-shaped radial runaway is an ACCELERATION with no ceiling
# — the avian clamp shows it as `vector.max_speed_m_s` = 75, and this line catches it.
wait 0.8                # S ended at +2.2 s; this is +2.3 s
key A 1.2
wait 1.0
mark f176-a-second-of-a-on-the-rope
assert speed < 55       # 🔴 the DRIVE is what moves him: drive_speed_m_s 52 + margin
assert speed > 3        # the control: he really is moving, he is not stuck against something
assert rope > 0

# ---- ACT 5 · §5E-b · THE YANK · hook while standing, NO key ⇒ off his legs -------------------
# The trigger lapsed at +4.6 s; the release drops him out of the swing. The warp catches him
# (position pinned, velocity zeroed, ropes released — `player::mod::apply_warps`) and he
# settles back onto his legs for the headline act.
wait 1.4                # +4.7 s: the trigger is gone
assert rope < 1
look 180 66.6
warp 45 0 -43
wait 0.5
mark f176-standing-again
assert speed < 7
assert height < 1.0     # the same stand ACT 1 pinned — this is what "off his legs" is against
# NO key from here to the end of the run. Under the old `in_the_air` gate this is the exact
# stance of his complaint: hooked, standing, looking at the anchor, and NOTHING happens. The

# Derivation of the window: the stance is 2.4 deg below the clean-lift line (68.96 deg =

hook right 6.0
wait 4.5
mark f176-the-bite-yanks-him-off-his-legs

assert height > 1.3     # a metre of real rise: he LEFT the ground, no key held (§5E-b)
