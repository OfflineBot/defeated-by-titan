# f177-board — ⭐ THE MISSION BOARD, end to end, driven by nothing but look, movement and F.
#
#   the verdict:  ./target/debug/defeated_by_titan --headless --hub --script scripts/f177-board.txt --ticks 2000
#   the exit:     ./target/debug/defeated_by_titan --headless --hub --script scripts/f177-board.txt --ticks 2000 >/dev/null 2>&1; echo $?
#   the picture:  ./target/debug/defeated_by_titan --offscreen --screenshot docs/images/f177-board-open.png \
#                                --hub --script scripts/f177-board.txt --ticks 260
#
# ⚠️ The exit code needs its OWN run: a pipeline's `$?` is the LAST command's (`CLAUDE.md`).
# ⚠️ The picture run is CUT OFF on purpose and reports red — a screenshot is taken at the last
#    tick of its run, so it has to be aimed at a moment. The verdict is the first line, never
#    the second. Same split as `scripts/f070-hub.txt` and `scripts/f019-hq.txt`.
#
# > „wenn man in der hub auf ein board drueckt (F) dann kommt man in eine mission uebersciht in
# > der man auswaehlen kann was man machen will!" — the user, 2026-08-27 (`Q-059`).
#
# ---------------------------------------------------------------------------------------
# WHY THIS RUN EXISTS AT ALL, and why it is the only evidence there can be
#
# `--headless` and `--offscreen` build no window (`src/lib.rs`), `menu` is gated on
# `With<PrimaryWindow>`, and there is no script verb that can press `Esc` or click a plate
# (`FIND-189`). Every earlier attempt at a hub door died on exactly that. The board does not:
# it is a place in the world and one key on the keyboard, and both of those exist in every
# launch mode. So this file walks the whole loop with `look`, `W` and `F` and nothing else.
#
# ---------------------------------------------------------------------------------------
# WHAT THIS FILE CLAIMS — eight things, and every one of them is an `assert`
#
#   1. a cold `--hub` start stands in the HUB                         (`assert phase == 5`)
#   2. one `look` and one `W` reach the signpost — no `warp` anywhere  (the two lines of ACT 2)
#   3. F at it opens the overview and one more F CHOOSES              (see 4)
#   4. a HELD F deploys what the board is showing, and it is NOT the default door
#                                                       (`assert titans >= 2`, and see below)
#   5. the sortie can be WON                                          (`assert phase == 3`)
#   6. and a won sortie walks home through the debrief                (`phase == 6`, `== 5`)
#   7. the board opens a second time and a DIFFERENT mission is chosen
#                                                                     (`assert titans == 0`)
#   8. and that one is a breach: three kills do not win it            (`assert phase == 2`)
#
# ⚠️ **4 and 7 are the load-bearing asserts and they are discriminators, not decorations.**
# There is no `assert mission` verb, so which sortie flew is proven by what the sortie DOES:
#
#   `missions.ron`, entries in file order (13 of them, and the log says so on every open):
#     0 tutorial · 1 skirmish/recruit · 2 skirmish/veteran · 3 skirmish/elite
#     4 breach/recruit · 5..6 breach · 7..9 parcours · 10..12 escort
#
#   The default is entry 1, skirmish/recruit — `hub.deployments[0]`, „the door you find without
#   looking for it". ACT 4 taps F once, so the board shows entry 2, skirmish/**veteran**.
#
#     skirmish/recruit  waves start at 60 s  ·  kill_target 2
#     skirmish/veteran  2 husks at 0 s       ·  kill_target 3
#     skirmish/elite    3 titans at 0 s      ·  kill_target 5
#     breach/recruit    first wave at 20 s   ·  kill_target 0, and kills never win a breach
#
#   So `assert titans >= 2` two seconds after deploying excludes **recruit** (an empty field
#   for a minute), and `assert phase == 2` after two kills excludes it again (recruit would
#   already read WON). `assert phase == 3` after the third excludes **elite** (target 5).
#   That leaves exactly veteran, which is the entry one tap off the default — i.e. the tap
#   chose, and the hold flew what the tap had chosen.
#
#   ACT 8 taps twice more (veteran -> elite -> breach/recruit) and `assert titans == 0` two
#   seconds in excludes both skirmish levels that spawn at 0 s, while `assert phase == 2` after
#   three kills excludes recruit (2) and veteran (3). Nothing in `skirmish` survives both.
#
# ⚠️ **What this file cannot claim:** that a *plate* came up. A run with no window has no menu
# at all, and `Screen` is deliberately not moved in one (`src/menu/board.rs`). What comes up
# here is `hud::board`'s panel — the same list, from the same `menu::lobby::entries`, deployed
# by the same `DeployRequest` — and it is what the `--offscreen` picture above shows. The
# windowed half is `tests/menu.rs::f177_esc_shuts_the_plate_and_the_board_follows_it`.

# =========================================================================================
# ACT 1 — the cold start, and it is a place
# =========================================================================================
wait 1.5
assert phase == 5
assert titans == 0
mark f177-in-the-hub

# =========================================================================================
# ACT 2 — the walk. No `warp`: he goes there on his feet, from the spawn point.
# =========================================================================================
#
# `missions.ron: hub.spawn_m` is (0, 2, 0) and `hub.board` is (3.6, 1.8, -4.2) — 5.53 m away,
# against a reach of 4.0, so the board is something you WALK to. The bearing is
# atan2(-3.6, 4.2) = -40.6 deg, because `look 0` faces -Z and `look 90` faces -X.
# He walks into the signpost and stops against it, which is exactly „standing at the board".
look -40.6 0
key W 1.20
wait 0.60
mark f177-at-the-board

# =========================================================================================
# ACT 3 — F. The overview.
# =========================================================================================
key F 0.10
wait 0.40
mark f177-board-open

# =========================================================================================
# ACT 4 — one more F. That is the CHOICE: entry 1 -> entry 2, skirmish/veteran.
# =========================================================================================
key F 0.10
wait 0.40
mark f177-board-stepped

# =========================================================================================
# ACT 5 — a HELD F deploys it. 0.60 s against `hub.board.hold_s` 0.35.
# =========================================================================================
key F 0.60
wait 2.20
assert phase == 2
assert titans >= 2     # ⭐ veteran's wave stands at 0 s. recruit's field is empty for a minute.
assert kills == 0
mark f177-deployed-veteran

# =========================================================================================
# ACT 6 — the sortie, won with three cortex cuts out of a fall (veteran wants 3)
# =========================================================================================
#
# The arrangement is `scripts/f175-loop.txt` ACT 3's, re-aimed for `gravity_m_s2 -32`.
spawn titan husk 17.5 0 0
warp 15.75 18.5 0.8
look 0 0
wait 0.72
slash right 0.40
wait 1.60
assert kills >= 1
mark f177-kill-one

spawn titan husk 17.5 0 0
warp 15.75 18.5 0.8
look 0 0
wait 0.72
slash right 0.40
wait 1.60
assert kills >= 2
assert phase == 2      # ⭐ recruit's target is 2 and would read WON here. This is veteran.
mark f177-kill-two

spawn titan husk 17.5 0 0
warp 15.75 18.5 0.8
look 0 0
wait 0.72
slash right 0.40
wait 1.60
assert kills >= 3
wait 0.40
assert phase == 3      # ⭐ WON at three. Elite's target is 5 and would still read ACTIVE.
mark f177-won

# =========================================================================================
# ACT 7 — the way home
# =========================================================================================
#
# ⚠️ **The two waits are aimed, and the aim is measured.** `missions.ron: hub` holds the
# verdict for `verdict_s` 3.0 s and the debrief for `debrief_s` 1.2 s, both counted off the tick
# the verdict was decided on — so `Debrief` is the window [decided+180, decided+252] and there
# is nowhere else to read it. Measured 2026-08-28: the third cortex cut lands at t = 642..666
# and `f177-won` is marked at t = 767, which puts that window at [846, 897] once both ends are
# taken at their worst. The reads below land at t = 866 and t = 944 — inside it by 20 ticks and
# past it by 26. A first cut of this act read at t = 905 and got the hub, which is what those
# numbers are worth.
wait 1.65
assert phase == 6
wait 1.30
assert phase == 5
assert height < 3
mark f177-home

# =========================================================================================
# ACT 8 — ⭐ the board again, and a DIFFERENT mission. Two taps: veteran -> elite -> breach.
# =========================================================================================
look -40.6 0
key W 1.20
wait 0.60
key F 0.10
wait 0.40
key F 0.10
wait 0.40
key F 0.10
wait 0.40
mark f177-board-stepped-twice
key F 0.60
wait 2.20
assert phase == 2
assert titans == 0     # ⭐ breach/recruit's first wave is at 20 s. Both skirmish levels the
                       #    board could have been showing spawn at 0 s.
mark f177-deployed-breach

# =========================================================================================
# ACT 9 — and it is a BREACH: kills do not win it
# =========================================================================================
spawn titan husk 17.5 0 0
warp 15.75 18.5 0.8
look 0 0
wait 0.72
slash right 0.40
wait 1.60

spawn titan husk 17.5 0 0
warp 15.75 18.5 0.8
look 0 0
wait 0.72
slash right 0.40
wait 1.60

spawn titan husk 17.5 0 0
warp 15.75 18.5 0.8
look 0 0
wait 0.72
slash right 0.40
wait 1.60

assert kills >= 3
assert phase == 2      # ⭐ three kills, still ACTIVE. No skirmish level does that.
mark f177-breach-holds
