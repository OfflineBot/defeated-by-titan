# f018-budget — WHERE THE 300 GOES. A ledger of one ordinary sortie across Ashgate.
#
#   the verdict:  ./target/debug/defeated_by_titan --headless \
#                     --script scripts/f018-budget.txt --ticks 1600
#   the ledger:   DBT_GAS_LEDGER=1 ./target/debug/defeated_by_titan --headless \
#                     --script scripts/f018-budget.txt --ticks 1600 2>&1 \
#                     | grep -E 'MARK|gas ledger|assert|script run finished'
#
# The user, after playing, 2026-08-20: *„eine sache die mir noch auffällt. gas ist VIEL zu
# schnell weg!"*
#
# `scripts/f-018-gas.txt` measures the RATE of one consumer at a time and it is right about
# every number it asserts — and it cannot answer him, because a player never holds one button.
# This file holds the buttons a player holds, in the mix he holds them in, and the
# `DBT_GAS_LEDGER=1` accumulator in `src/vector/gas.rs` splits the same debit four ways as it
# happens. What it is for is the LEDGER, not the asserts: the asserts only pin the ledger's
# headline so the file goes red if the mix ever changes underneath it.
#
# The legs are cut so that each one adds exactly ONE verb to the one before it, and every leg
# runs on the same anchored rope:
#
#   A  the rope alone, nothing held             measured  0/s
#   B  + W (the verb he asked for himself)      measured  0/s   <- ⭐ AND THAT IS THE FINDING
#   C  + Shift on top of the W                  measured 18/s   <- gas_boost_per_s alone
#   D  + Ctrl on top of both                    measured 24/s   <- + gas_reel_per_s
#   E  one dodge                                measured 45 flat, 15 % of the tank
#
# ## THE LEDGER THIS FILE WAS WRITTEN FOR (`docs/FINDINGS.md` FIND-139)
#
# The first run of it, 2026-08-20, **before** the repair — 300 gas, gone in 9.1 s of spending:
#
#     boost   98.1   32.7 %      steer  144.8   48.3 %
#     reel    12.1    4.0 %      dodge   45.0   15.0 %   (ONE press)
#
# `Steer` was the largest line item in the game — bigger than the boost he actually presses —
# and the sortie's own geometry says it bought **nothing**: `rope_steer` multiplies the pull by
# `max(0, l̂ · r̂)`, a player hangs *under* his anchor and looks where he is going, so the pull
# was `Vec3::ZERO` for 99 of 99 sampled steer ticks (mean 0.0012 of `air_pull_m_s2`). The bill
# followed the BUTTON, the thrust followed the GEOMETRY, and nobody held the two together.
#
# After `src/vector/gas.rs::steer_has_effect` (same binary, same script, same seed):
#
#     boost  151.8   50.6 %      steer    2.9    1.0 %
#     reel    12.1    4.0 %      dodge   45.0   15.0 %   total 222.9 of 300, 77.1 left over
#
# ⚠️ **THE PERCENTAGE COLUMN IS DATED 2026-08-20 AND IT IS A RECORD, NOT A CURRENT READING.**
# It was measured against `gas_tank: 300`. Later the same day the user raised the tank to
# 15000 (docs/QUESTIONS.md Q-046), so the identical sortie now reads `total 222.9 of 15000,
# 14777.1 left over` and every share above is 50x smaller — 1.49 % in total. **The absolute
# gas figures and the ratios between them are what this file measures and they did not move**;
# that is why they are kept verbatim instead of being rebased into meaninglessness.
# `src/vector/gas.rs` prints the live percentage with two decimals since that day, precisely
# so this split stays readable at a tank this size (it used to round to `0%` and `1%`).
#
# **The trajectory is unchanged where it mattered** and it has to be: `air_control` adds
# `rope_steer(...)` only behind `grant.steer`, and in every tick that lost its grant that term
# was `Vec3::ZERO` — the same `look` either way. What changed is only the price of it.
#
# The stand is `scripts/f003-ashgate.txt`'s measured arc — (0, 58, 47.5) at `look 0 0`, yaw 0
# down the main street toward the wall — because that one is known to anchor and known to swing
# (measured there: 31.4 m/s at the bottom of the arc, apex back at 57.5 m).

wait 1.5                 # world, camera, meshes and the render pipelines come up
warp 0 58 47.5
look 0 0                 # yaw 0 = -Z, down the main street
wait 0.3                 # the warp takes effect one tick after it is written

mark f018-budget-start
assert gas == 15000        # a full tank: nothing has been paid for yet
assert height > 56.3     # 0.3 s of fall from the warp at 58 m, and NOT a ledge — the old comment
                         # said "standing on the ledge the warp puts him on" and the numbers say
                         # free fall to four decimals. It is timed against `gravity_m_s2`:
                         #     h = 58 - 0.5 * g * (0.3 s + 1 tick)^2
                         #       = 58 - 16 * 0.31667^2 = 56.396 m   (it was 57.005 at g -20)
                         # Measured 56.392. The floor keeps the old 0.095 m of margin under the
                         # derived value (56.9 sat 0.095 under 56.995), re-anchored, not widened.

# =========================================================================================
# LEG A — the rope alone. **A swing is free**, and that is the baseline everything else is
# read against.
# =========================================================================================

hook right 12.0          # one hold for the whole sortie: the fire is an EDGE, holding refires
wait 2.0                 # nothing
mark f018-budget-a-rope-only
assert rope >= 1         # the rope is on him for every leg below
assert gas == 15000        # ⭐ swinging costs nothing

# =========================================================================================
# LEG B — + `W`. The verb the user asked for („das a d sorgt dafür dass man nicht immer direkt
# zum seil gezogen wird", and W hauling you where you look) — and the one that is billed.
# =========================================================================================

key W 3.0
wait 3.0
mark f018-budget-b-steer
# 🔴 RED ON PURPOSE SINCE 2026-08-29, AND THE FIVE GAS LINES BELOW ARE ONE FAULT, NOT FIVE.
# `gravity_m_s2` went -20 -> -32, the swing this act is flown on got deeper and faster, and the
# pose at this mark is no longer the one the act was cut for. The gas MODEL did not move:
#
#   DBT_GAS_LEDGER=1 ... | grep 'gas ledger'      at this mark:
#     spent=13.2  boost=1.5  steer=11.7  reel=0.0 | wanted_ticks steer=44  granted_ticks steer=44
#
# `wanted == granted` on every consumer: the game billed exactly the ticks it delivered thrust
# on. What changed is that `l̂ · r̂` is now positive for 44 of this leg's 180 ticks, where at
# -20 it was positive for none — so `W` is no longer inert here and the tank moves by 10.397.
# THE PER-LEG COSTS ARE STILL EXACT, which is the proof that only the arc moved:
#
#   line  leg          measured tank   this leg cost   derived
#   121   B  W          14989.603        10.397        steer, pose-dependent — the one that moved
#   138   C  +Shift     14927.073        62.530        3 x gas_boost_per_s 18 = 54, + 8.53 steer
#   150   D  +Ctrl      14886.007        41.066        2 x (18 + 6), less the ticks the reel was idle
#   164   E  +C dodge   14841.007        45.000        gas_dodge 45, FLAT, to three decimals ✅
#   174   F  +4 s boost 14768.754        72.253        4 x gas_boost_per_s 18 = 72.000 ✅
#
# E and F are right to the last digit at BOTH gravities, so no rate here is aimed at a constant.
# ⚠️ DO NOT re-aim the five floors onto the new absolutes: they are absolute only because the
# script language has no `assert gas_delta`, and every one of them carries this leg's 10.397
# forward. The repair is to RE-CUT THE ACT onto a stand whose swing still has `l̂ · r̂ = 0` —
# which is what this line's own comment has asked for since it was written.
assert gas == 15000        # ⭐ measured 300.000. THREE SECONDS OF `W` ON A TAUT ROPE, AND THE
                         # TANK HAS NOT MOVED — because in this pose the rope pull is
                         # `max(0, l̂ · r̂) = 0` and the game delivers nothing. It used to cost
                         # 48 gas here. Whoever makes this line go red has either given `W` a
                         # thrust in this pose (good — then re-cut the act) or put the bill
                         # back on the button (`docs/FINDINGS.md` FIND-139).

# =========================================================================================
# LEG C — + `Shift`. Boost and steer are wanted on the very same tick of a swing, and both are
# billed on it: 18 + 16 = 34/s.
# =========================================================================================

key W 3.0
key Shift 3.0
wait 3.0
mark f018-budget-c-steer-and-boost
assert gas < 14946.4       # ⭐ measured 14945.735 = 15000 - 3 x 18. The boost is the WHOLE bill of
assert gas > 14945.0       # this leg: `Shift` is billed, the inert `W` beside it is not.

# =========================================================================================
# LEG D — + `Ctrl`. All three continuous consumers at once: 40/s.
# =========================================================================================

key W 2.0
key Shift 2.0
key Ctrl 2.0
wait 2.0
mark f018-budget-d-all-three
assert gas < 14895.5       # ⭐ measured 194.367 = 245.7 - 2 x (18 + 6) - 2.9. The 2.9 is `Steer`
assert gas > 14893.5       # billed on the eleven ticks it really pulled: the reel shortens the
                         # rope, the swing carries him up past his own anchor, and for eleven
                         # ticks `l̂ · r̂` is finally positive. **That is what an honest steer
                         # bill looks like** — eleven ticks, not 543.

# =========================================================================================
# LEG E — one dodge. `C` is the dodge key (src/net/local.rs); 45 flat, billed on one tick.
# =========================================================================================

key W 0.6                # a dodge with no movement key held has no direction and costs nothing
key C 0.1
wait 0.6
mark f018-budget-e-dodge
assert gas < 14850.0       # ⭐ measured 149.367 = 194.367 - 45.000, to the last digit: one press
assert gas > 14848.7       # of `C` is 15 % of the tank and it is billed flat, not per second.

# =========================================================================================
# LEG F — four more seconds of boost. **This act used to be flown on an empty tank.**
# =========================================================================================

key W 4.0
key Shift 4.0
wait 4.0
mark f018-budget-f-dry
assert gas > 14776.5        # ⭐ measured 77.067 = 149.367 - 4 x 18. **The sortie no longer runs
assert gas < 14778.0        # dry**: the same eighteen seconds of flying that emptied the tank
                         # before this repair now end with 77 gas — a quarter of it — in hand.
                         # Total for the sortie: 222.9, of which 151.8 is the boost he presses.

end
