# F-030 — the cut: a blade swept along one tick of the player's fall crosses the amber cortex
# on the husk's nape, and the husk dies.
#
# cargo run -- --offscreen --script scripts/f030-cortex.txt --ticks 68 \
#              --screenshot docs/images/f030-cortex.png
#
# and, as a SEPARATE run, the one that returns a usable exit code:
#
#   cargo run -q -- --headless --script scripts/f030-cortex.txt --ticks 700
#
# ⚠️ **A `--screenshot` run is not a verdict.** `debug::screenshot::exit_when_written` owns the
# ending and writes `AppExit::Success` the moment the PNG is on disk, without ever reading
# `run.failures` — so the command above exits 0 even when the asserts in this file are RED, and
# the assert summary never prints (`docs/FINDINGS.md` FIND-073). Only the `--headless` run
# reports "N asserts held" and returns an exit code worth reading. Its tick count is
# deliberately generous: overshooting the script's own end is free, undershooting truncates the
# run and hides the summary (FIND-032).
#
# ## Why the player FALLS instead of flying
#
# `gear.ron: blades.min_speed_m_s` is 8.0 and `game.ron: player.run_speed_m_s` is 6.0 — a
# running player cannot cut anything, by design ("damage comes out of speed"). The Vector Gear
# reaches 30 m/s and more, but hooking, reeling and boosting cannot be aimed from a script
# accurately enough to pass a 1.10 m sphere. Gravity can: at −20 m/s² a fall of 11.2 m is
# 21 m/s, and it is reproducible to the tick.
#
# ## Why x = 15.75 and not 16.7
#
# The husk's body capsule has a radius of `width_fraction × height / 2` = 1.25 m and the player
# capsule 0.35 m, so anything closer than **1.60 m** to his axis is a collision and not a pass.
# 1.75 m leaves 0.15 m of air. The blade is `reach_m` = 1.60 m long and hangs from the hand at
# eye height, so its tip reaches x = 17.35 — 0.15 m inside a cortex sphere of radius 0.55 m
# centred on x = 17.5. **`reach_m` and the body radius are 1.60 m and 1.60 m**: there is no
# margin at all in these numbers, and that is a finding about the RON, not about the cut.
#
# ## Why the cut waits for `Recover`
#
# The pose is a pure function of `(state, ticks_in_state)`, and only `Recover` and `Idle` have
# `lean_deg: 0` (`src/titan/pose.rs:56-80`). A husk 1.8 m away is inside `attack_range_m` = 6.0,
# so he goes `Idle → Pursue → Windup` on the first two ticks and his torso leans 12° over the
# next 36 — which carries the cortex almost a metre. `Windup` 36 + `Strike` 12 ticks put
# `Recover` at tick 50..73, and the cut lands inside it, against an upright body.
#
# ## Why z = 0.8 and not 0.55
#
# The cortex sits `head_m / 2` = 0.55 m **behind** the head's axis (`src/titan/rig.rs:434-440`),
# so a blade at z = 0.55 passes through its centre. 0.8 gives up 0.25 m of that margin — the
# blade still crosses the sphere (0.47 m of offset against 0.55 + 0.12 of radius) — and buys a
# camera angle that has the titan in the frame instead of one metre of his flank.
#
# ## Why the camera only turns afterwards
#
# The blade hangs at the player's side, perpendicular to the look direction — you cut what you
# fly past, not what you look at (`src/blades/cut.rs: blade_segment`). So the look has to stay
# at yaw 0 until the blade is through, and only then turns onto the titan for the picture.
#
# ⚠️ **The amber cortex is not in either picture, and that is geometry, not an oversight.** The
# cutting player is necessarily *beside* the nape at nape height, and the cortex protrudes
# **backwards** out of the head — from where the blade is, it is flush with the head's face.
# What the pictures carry is the F3 overlay: the tick, the player's position to the digit, and
# `titan#1 Death`. The swept blade capsule as a gizmo, which the criterion also asks for, needs
# `src/debug/gizmo.rs` and that file belongs to another job.
# 1.5 s of lead-in before anything happens: under `--offscreen` the render pipelines and the
# block meshes are still coming up in the first second, and a screenshot taken into that is
# evidence of nothing (`scripts/p1-overlay.txt` uses the same 1.5).
wait 1.5
spawn titan husk 17.5 0 0
warp 15.75 18.5 0.8
look 0 0
key F3 0.05
wait 0.90
slash right 0.40
wait 0.08
look -90 -6
mark cortex-cut
wait 0.10
assert titans == 1
wait 1.10
assert titans == 0
