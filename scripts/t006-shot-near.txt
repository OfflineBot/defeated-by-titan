# t006-shot-near — the same image from the player's perspective: what a 1.8 m human sees
# here.
#
#   cargo run --features wayland,audio -- \
#       --script scripts/t006-shot-near.txt --ticks 110 --screenshot docs/images/t006-player-view.png
#
# The actual purpose: **scale.** The block heights in assets/data/maps.ron are derived from
# scale.ron and have never been seen to this day. An image from eye height is the only
# check that can confirm or refute "4.5 m is a small house".
#
# ⚠️ As in t006-shot-far.txt: `look` has no effect as long as
# src/render/camera.rs::rotate_camera is an empty stub — the camera looks along -Z.
# What is visible in this image is therefore purely a question of `warp`.

wait 1.5                # let world, camera, meshes and the render pipelines come up
look 0 0                # look along -Z, the axis contract (docs/conventions.md)

# On the ground, four meters in front of the origin. In the looking direction stand the
# 4 m cube at z = -12, behind it on the left the 8 m block and on the right the two tall
# ones — four sizes in one image, held against an eye height of 1.6 m.
warp 0 0 4

wait 0.3                # the warp takes effect one tick later than it is written
assert height < 0.5      # stands on the ground and not inside it
assert height > -1       # and has not fallen through the ground
mark near
wait 5                  # keep the run alive: if it ends, the process ends before the image
