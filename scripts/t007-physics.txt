# t007-physics — the player under REAL physics: does he stand on the ground, or in it?
#
#   cargo run -- --offscreen --script scripts/t007-physics.txt --ticks 200 \
#       --screenshot docs/images/t007-physics.png
#
# and, as a SEPARATE run, the one that returns a usable exit code:
#
#   cargo run -q -- --headless --script scripts/t007-physics.txt --ticks 900
#
# ⚠️ **A `--screenshot` run is not a verdict.** `debug::screenshot::exit_when_written` owns the
# ending and writes `AppExit::Success` the moment the PNG is on disk, without ever reading
# `run.failures` — so the command above exits 0 even when the asserts in this file are RED, and
# the assert summary never prints (`docs/FINDINGS.md` FIND-073). Only the `--headless` run
# reports "N asserts held" and returns an exit code worth reading. Its tick count is
# deliberately generous: overshooting the script's own end is free, undershooting truncates the
# run and hides the summary (FIND-032).
#
# Since 2026-08-09 nothing catches the player at y = 0 any more. The hand-written
# `translation += velocity * dt` and its hard-coded ground plane are gone; what carries him
# is the collider of `maps.ron: blocks[0]`, whose top edge lies exactly at y = 0.
#
# **The pitch is the point of this image.** The camera hangs off the player at 1.6 m eye
# height and can only look out of his eyes — so "does he stand ON the ground" is not
# visible from a level view. At -20 degrees the lower edge of the frame lies about 1.4 m in
# front of his feet: a player sunk into the ground would have his camera under the surface
# and the image would be dark; one floating half a meter up would push the near ground edge
# measurably away. Between the two the picture is exactly this one.
#
# The three `assert` lines are what makes the run a test — they measure the same y the image
# shows, and they fail the run with a non-zero exit code (prompts/init.md §12b).

wait 1.5                # world, camera, meshes and the render pipelines come up (90 ticks)
look 0 -20              # yaw along -Z (the axis contract), pitch down at the ground
wait 1.5                # fall the 2 m from the spawn point and settle (90 ticks)

mark t007-standing
assert height > -0.05   # not sunk into the ground
assert height < 0.05    # and not floating above it
assert speed < 0.05     # standing means standing, not sliding

wait 5                  # keep the run alive: if it ends, the process ends before the image
