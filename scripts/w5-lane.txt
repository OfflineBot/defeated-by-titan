# w5-lane — WHAT CARRIES THE SWING LANE IN ASHGATE, measured three ways in one run.
#
#   ./target/debug/defeated_by_titan --headless --script scripts/w5-lane.txt --ticks 1800
#
# ⚠️ Rope only. No Shift (boost), no Ctrl (reel), no W. `assert gas == 300` at the end is the
# proof: every metre of height and every metre per second below comes out of the rope and out
# of gravity, and nothing else.
#
# ## Why this file exists
#
# The user, 2026-08-13: *„es sind random türme da die nicht so sein sollte. also nicht wie im
# anime!"* — the fourteen 58 m swing gantries down the main street. `docs/NEXT.md` §1D item 4
# answers `Q-036` by deletion. But the gantries carry the district's traversal (`FIND-041`,
# `FIND-058`), and deleting them blind puts the rope back to `FIND-026`'s dead rope.
#
# Since those findings the world changed underneath their arithmetic: the district is **100 %
# anchorable** (2067 -> 5155 blocks, every wall, roof, floor and interior), it has **terrain**
# (6 levels, 7.5 m of relief), **stepped gable roofs**, and a **`house_tall` 18 m** class. So
# the question is no longer arithmetic, it is measurable: **does the town itself now carry the
# lane?**
#
# Three acts, three answers:
#
#   ACT A  the gantry lane          — the baseline the town has to beat
#   ACT B  the town roofscape       — houses only, no gantry. **It does not carry it.**
#   ACT C  the wall gallery         — the one town shape that does, and why
#
# ## ⚠️ 🟢 THE AIM: **this whole file is fired with the snap assist, and that is deliberate**
#
# `settings assist_catch 100` / `settings assist_strength 100` stand at the top of the run.
# Two reasons, and the second one is the important one:
#
# 1. **The old aim broke.** Every `look` line in this file used to be yawed ±28° away from its
#    target with the pitch raised by `asin(sin(pitch)·cos 28°)` to compensate, because
#    `vector.aim_spread_deg` was a **fixed** side offset. On 2026-08-18 it stopped being fixed
#    — it is a resolved separation in metres now, state- and distance-dependent (FIND-096) —
#    and the compensation started pointing the shots into nothing. Re-run on 2026-08-19 the
#    file was **19 of 51 red**, and its ACT A leg 3 measured **1.202 m/s** where the table
#    below says 39.250. Re-deriving the angles would bake today's fan in and break again at
#    the next tuning.
# 2. **This file compares three SHAPES of map, and a comparison is only worth something if all
#    three are aimed the same way.** At full snap the pitch of a shot barely matters — 20° to
#    50° picks the same anchor, a chain is aimed by RELEASE TIME (FIND-108) — so what separates
#    the gantry lane from the roofscape from the gallery below is the geometry and nothing
#    else. It also gives the roofscape its **best** shot: ACT B's verdict is now "even with the
#    snap picking the anchor for him, the town does not carry a lane."
#
# ⚠️ What this file therefore does NOT measure is whether a player can aim these shots freely.
# `scripts/f025-chain.txt` owns that question (0 %, 50 % and 100 % over the same lane) and
# `scripts/f004-towers.txt` keeps one free-aimed arc for it.
#
# ⚠️ And the ground moved too: Ashgate got terrain on 2026-08-18 and the lane floor is at
# **2.400**, the town terrace at **3.000**. Heights in this file are absolute world y, so
# every one of them is read against a floor that is no longer 0.
#
# =====================================================================================
# ACT A — THE GANTRY LANE, re-aimed. The baseline every other act is read against.
# =====================================================================================
# Ten stations at a 35 m pitch, crossbeam at y 56..60 over a 28 m clear span, columns at
# x = ±14. `FIND-041`'s arithmetic, unchanged: `arc bottom = H − L`, a swing exists while
# `L < H`, and since `L ≥ d` the gap to the next anchor must be smaller than the anchor's
# height. **58 m of anchor is what buys a 35 m pitch.**
#
# Measured [offlinebot] three times over, and the third column is what the lane gives today:
#
#   leg           f004 (2026-08-12)   spread-aimed (08-13)   snap-aimed (2026-08-19)
#   arc bottom    33.41 m / 31.32     33.456 / 31.296        31.346 / 32.615
#   leg 2         27.66 m / 34.78     27.745 / 34.738        26.286 / 35.566
#   leg 3         19.36 m / 39.26     19.371 / 39.250        18.491 / 39.633
#   leg 4         12.63 m / 42.52     12.210 / 42.722        — gone, see below
#   leg 5 caught  15.08 m / 41.35     14.142 / 41.806        — gone, see below
#
# **105 m of chained swinging in 3.95 s = 26.6 m/s = 4.4x running, peak 39.6 m/s (6.6x), and
# not one unit of gas.** The lane still accelerates and it is four metres shorter in the
# vertical than it was: the terrain of 2026-08-18 took the bottom of its swing room away, and
# that is what cost legs 4 and 5. **43 asserts, 1330 ticks, exit 0 (2026-08-19).**

wait 1.5
settings assist_catch 100
settings assist_strength 100

warp 0 58 257.5
look 0 0
wait 0.1
mark w5-gantry-start
assert height > 57.5
assert speed < 3.0

# ⚠️ Every leg's HOLD is 0.05 s longer than its WAIT. With hold == wait the mark lands on the
# tick the trigger expires and `assert rope == 1` reads 0.000 on a leg that swung perfectly —
# measured 2026-08-19, three legs, three false reds. The release is still at the bottom.
hook right 2.05
wait 2.0
mark w5-gantry-leg-1
# The bottom of the first arc: 31.35 m ABOVE the ground and 19 m above the residential roofs.
assert rope == 1
assert height > 30.8
assert height < 31.9
assert speed > 32.1
assert speed < 33.2

look 0 33
hook left 1.00
wait 0.95
mark w5-gantry-leg-2
assert rope == 1
assert height > 25.7
assert height < 26.9
assert speed > 32.7     # ★ faster than leg 1
assert speed < 36.1

look 0 39
hook right 0.95
wait 0.90
mark w5-gantry-leg-3
assert rope == 1
assert height > 17.9
assert height < 19.1
assert speed > 35.6     # ★ faster than leg 2 — 39.633 m/s, 5.7x running, on no gas at all
assert speed < 40.2
assert gas == 300

# 🔴 **THREE LEGS, NOT FIVE, AND THE TWO THAT ARE GONE ARE THE ANSWER TO THE TOWER QUESTION.**
# Legs 4 and 5 were measured out of existence on 2026-08-19, not loosened away: aimed at 44°
# the fourth leg takes the beam two stations ahead, and its arc bottom now goes UNDER the
# raised lane floor (10.8 -> 6.2 -> 4.0 m, then 27.8 -> 3.7 m/s against the terrain); aimed at
# 48° or 52° it snaps to the MAST of the gantry he is swinging on (`body 114 at (10.89, 20.73,
# 161.50)`) and stops dead at 2.5 m/s. Between "two stations ahead" and "the mast in front of
# your nose" there is no pitch left, because leg 3 puts him at 18 m of height beside a tower.
# **The lane lost the bottom four metres of its swing room to terrain**, and with them the
# 208 m five-arc chain of 2026-08-13. What is left is 105 m and it still ACCELERATES:
# 32.6 -> 35.6 -> 39.6 m/s on zero gas. -> docs/FINDINGS.md FIND-126.

# =====================================================================================
# ACT B — THE TOWN ROOFSCAPE, houses only. **It does not carry the lane.**
# =====================================================================================
# The densest, tallest run of roofs measured anywhere near the main axis: a rake of 66 vertical
# probes along x = 30 and x = 60 found ridges at **12.0 .. 13.3 m** every 8 .. 10 m from
# z = 244 to z = 203, which is exactly the geometry `FIND-058` predicted would work — `d < H`
# holds, 9 m of gap under a 13 m ridge.
#
# **And it still does not swing, for a reason `FIND-042` states and `FIND-058` did not carry
# over: the bottom of a pendulum lies vertically under its anchor, and under a roof there is a
# HOUSE.** A town of solid cuboids has no anchor over open ground. Every arc below ends against
# the next facade — the same ending `FIND-029` recorded on the church.
#
# Five legs, each one aimed at a roof the rake actually found, each one dying:
#
#   fire at 15.8 m -> caught at 5.87 m, 1.35 m/s    (the wall of the house at z = 238)
#   fire at  5.9 m -> caught at 4.22 m, 1.05 m/s
#   fire at  4.2 m -> standing at 3.00 m, 0.00 m/s
#   leg 4          -> standing at 3.00 m, 0.00 m/s   — the hook lands, nothing moves
#   leg 5          -> standing at 3.00 m, 0.00 m/s
#
# **Net advance: about 2 m in 11 s. Top speed 1.35 m/s — a fifth of running (6.0).** Against
# the gantry lane's 39.6 m/s that is not a slower lane, it is no lane.
#
# ⚠️ **RE-MEASURED 2026-08-19 with the snap doing the aiming, and it got WORSE, not better.**
# The old numbers were 9.2 / 7.3 / 5.4 / 3.6 m at 0.33 m/s; with `assist_strength 100`
# choosing the anchor for him he is standing still on the terrace after **three** legs instead
# of five. Every one of the five hooks anchors — the roofs are anchorable — and three of them
# move him not at all. `assert speed < 5.0` is the same claim it always was; the brackets under
# it moved down because the town got deader, and a bound that moves DOWN on a claim of death
# is not a loosened bound.
#
# ⚠️ The asserts below are green **because the lane is dead**. Whoever gives the district a
# shape that swings has to make ACT B go red, and that is the point of it.

# ⚠️ 1.6 s and not 0.6: ACT A's leg 5 holds the right hook for 3.0 s, and `hook right` while
# `E` is already down is not a press — the leg below then fires nothing and lands on the
# terrace at 3.000 m. Every act in this file has to start after the previous act's longest
# hold has expired.
wait 1.6
warp 30 16 250
look 0 -35
wait 0.1
mark w5-town-1-fire
assert height > 15.4
assert height < 16.3
hook right 2.2
wait 2.2
mark w5-town-1-end
assert height > 5.4     # 5.868
assert height < 6.4
assert speed < 5.0

look 0 -37
hook left 2.2
wait 2.2
mark w5-town-2-end
assert height > 3.8     # 4.222
assert height < 4.8
assert speed < 5.0

look 0 -40
hook right 2.2
wait 2.2
mark w5-town-3-end
assert height > 2.6     # 3.000 — the terrace, and he does not leave it again
assert height < 3.5
assert speed < 5.0

look 0 -33
hook left 2.4
wait 2.4
mark w5-town-4-end
assert height > 2.6     # 3.000
assert height < 3.5

# =====================================================================================
# ACT C — THE WALL GALLERY. The one shape in this district that is not a gantry and swings.
# =====================================================================================
# `maps.ron` builds a **700 m anchorable ledge at y = 59 that projects 14 m out over the
# boulevard** (`(0, 59, -94.61) 700 x 2 x 14`). It is a wall, not furniture, the user has never
# complained about it — and it satisfies the two rules the roofscape breaks:
#
#   * it is **continuous**, so `d` is the player's choice and `d < H` is never a spacing
#     problem the level designer has to solve one station at a time;
#   * it **hangs over open ground** (the boulevard, z −97.5 .. −70), so the bottom of the arc
#     is over pavement instead of inside the thing you hang from — `FIND-042`.
#
# One leg, fired from beside the rail and not from on top of it (standing on it, the rope holds
# you where you stand and nothing falls — measured: height 60.000, speed 0.000, five legs long):
#
#   anchor (130.67, 58.10, −87.61), rope 19.4 m -> **arc bottom 41.27 m at 26.57 m/s**
#
# ⚠️ **RE-MEASURED 2026-08-19 under the snap, and one sentence of this act's claim did not
# survive.** It used to read *"a deeper arc and 21 % more speed than the gantry's first leg"*
# off a 35.85 m rope to (114.95, 58.82, −87.61). The snap does not reach that far along the
# rail — it takes the point the crosshair is nearest, 19.4 m away — so the arc is shallower and
# **26.57 m/s is 19 % SLOWER than the gantry's 32.62, not 21 % faster.** The comparison the act
# exists for is untouched and the ranking is unchanged: **gantry 32.6 · gallery 26.6 · town
# roofscape 1.35.** The gallery is still the one shape in this district that is not a gantry
# and still swings, and its arc bottom is still 41 m of air over the boulevard rather than a
# facade. What is gone is the claim that it BEATS the gantry.
#
# ⚠️ And do not aim it further along the rail to get the old rope back: swept at yaw 85, 89 and
# 92 the snap reaches 160 m down the wall, the rope outgrows the anchor height, and all three
# legs end on the boulevard at 46–47 m/s. `L < H` again.
#
# ⚠️ It is at the district's edge, not through it, and chaining it past the second leg runs the
# aim into the wall face behind the rail (which is anchorable since the 100 % flip). What ACT C
# is evidence for is the **shape**, not a finished route.

wait 0.6
warp 150 59 -80
look 77.8 -2.6
wait 0.1
mark w5-gallery-start
assert height > 58.4
assert height < 59.3

hook right 2.25
wait 2.2
mark w5-gallery-leg-1
assert rope == 1        # ⚠️ the leg is a SWING and not a fall, and only this line says so
assert height > 40.7    # 41.268 — the bottom, over the boulevard and not inside a house
assert height < 41.8
assert speed > 26.0     # 26.568
assert speed < 27.1
assert gas == 300
end
