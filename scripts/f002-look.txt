# f002-look — image A of the pair: same place, looking straight ahead along -Z.
#
#   cargo run --features wayland,audio -- --offscreen \
#       --script scripts/f002-look.txt --ticks 130 --screenshot docs/images/f002-look.png
#
# Together with scripts/f002-look-turned.txt this is the IMAGE EVIDENCE for
# src/render/camera.rs::rotate_camera: two images from **the same position** with a
# different `look`. If they look the same, the camera rotation has no effect —
# no matter what tests/render.rs says. The one criterion a unit test does not replace.
#
# ⚠️ The 130 belong to THIS file. `wait 1.5` is 90 ticks at 60 Hz, `wait 0.3` another
# 18; so the image is taken about 20 ticks after the last `assert`. Whoever changes the
# tick count changes the image.
#
# ⚠️ `--offscreen`, not `--headless`: --headless switches the wgpu adapter off
# (backends: None) and returns exit 1 with no file. And not the window path either: there
# the compositor decides the image size, not the command (docs/ACCEPTANCE.md).

wait 1.5                # let world, camera, meshes and the render pipelines come up
look 0 0                # look along -Z, the axis contract (docs/conventions.md)

# On the ground, four meters in front of the origin — the same spot as in
# f002-look-turned.txt. Straight ahead stands the sand-brown 4 m cube at z = -12, on the
# left the brick-red 8 m block, on the right the stone-gray ones (11.5 m and 12 m) — all
# four out of `blocks` in assets/data/maps.ron. What stands behind them comes out of the
# `layout` of the same file.
#
# ⚠️ That ties this image to maps.ron: whoever changes the city changes it. The PART the
# image is meant to prove does not hang on that — that look direction and image belong
# together is shown by comparing the two PNGs, not by their content.
warp 0 0 4

wait 0.3                # the warp takes effect one tick later than it is written
assert height < 0.5      # stands on the ground and is not floating above it
assert height > -1       # and has not fallen through the ground
assert titans == 0     # the world starts out empty
mark f002-look-straight
wait 5                  # keep the run alive: if it ends, the process ends before the image
