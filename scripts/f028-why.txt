# F-028 — a pull that finds nothing now says WHY, and the reasons differ.
#
#   ./target/debug/defeated_by_titan --headless --script scripts/f028-why.txt --ticks 600
#   ./target/debug/defeated_by_titan --headless --script scripts/f028-why.txt --ticks 600 >/dev/null 2>&1; echo $?
#
# PINS: the two STANCES, in metres — where each pull is fired from, and that the player is
# still standing there afterwards. It pins **no** speed, no gas and no impact: a hook that
# anchors and one that finds nothing are indistinguishable in this vocabulary until somebody
# reels (measured below), so the verdict itself is read out of the log line and the asserts
# exist to prove the shot was taken from the place the act names. That is exactly the guard
# `FIND-204` found missing, when act 2 stood 50 m outside the map and this file exited 0.
#
# ## The three acts, and what each of them is the evidence for
#
# 1. **Straight up from 400 m.** Nothing within `vector.hook_range_m` on that line and nothing
#    beyond it either. `NothingInRange` — *"turn"*.
# 2. **The world fence, 10 m in front of him on the boulevard.** `SurfaceHoldsNothing` —
#    *"aim past it"*.
# 3. **A husk 6 m in front of him.** He ANCHORS. That is the act's whole point, and it is a
#    control on a decision, not a miss.
#
# 🔴 **ACT 2 AIMED AT THE HUSK UNTIL 2026-08-29 AND MEASURED THE OPPOSITE OF ITS OWN PREMISE.**
# The header said *"a titan carries no `shared::Body`, so the ray ends on a surface that holds
# nothing — B-007 exactly"*. **`B-007` was closed on 2026-08-19**: `F-029` put
# `Body { mask: SOLID | ANCHORABLE }` on the titan rig root **on purpose**, so that a rope bites
# a walking titan and rides him, and so that a titan stops hiding the wall behind him
# (`tests/titan.rs::f029_a_rope_bites_a_walking_titan_and_rides_him`). The premise went stale
# ten days before `FIND-204` re-aimed the act onto the husk it was written for, and the re-aim
# restored a stance that had already expired. Measured here on 2026-08-29:
# `hook Left of player 1 anchored on body 4003 at 0.35 6.34 -88.55`.
# **The script was stale, not the game** (`docs/FINDINGS.md` FIND-211).
#
# ## So what still holds nothing? Exactly one thing, and it is invisible
#
# The run's own log says `map "Ashgate": 4002 blocks built ... 4002 of them anchorable` — the
# district is 100 % anchorable and carries no `anchorable: false` block at all. The **world
# fence** (`world::bounds::build_bounds`, `F-012`) is the one solid surface in this map that
# holds no anchor: four static `Collider::cuboid` panels with **no `Body`**, so `vector::aim`
# resolves them to `body: None` and `miss_reason` answers `(Some(point), false)` —
# `SurfaceHoldsNothing` (`docs/FINDINGS.md` FIND-200).
#
# **The control, run 2026-08-29 and it is one line.** Add
# `Body { half_size_m: panel.size_m * 0.5, mask: SOLID | ANCHORABLE }` to the panel bundle in
# `world::bounds::build_bounds` — FIND-200's own rollback point — rebuild, and this same act 2
# reads `hook Left ... left the hand: 11.75 m` / `anchored on body 4003 at 350.18 7.53 -83.75`
# instead of `SurfaceHoldsNothing`. Restored, it reports the miss again.
#
# ⚠️ **And what the control also measured: an anchor is not a pull.** With the fence made
# anchorable and the rope held for 3.0 s at pitch 55, the player stayed at height **0.050 m**
# and speed **0.000 m/s** — a rope reels only when the gear is asked to. So `assert speed` and
# `assert height` cannot tell a hit from a miss here, and this file does not pretend they can.
# What they CAN tell is that the shot was fired from the boulevard and not from 50 m outside
# the map, and that no recovery picked the player up between the acts.

wait 1.5

# ── ACT 1 · open sky · NothingInRange ───────────────────────────────────────────────────
# 400 m up over the district, looking further up: nothing on that line inside
# `vector.hook_range_m` (500 m) and the probe ray finds nothing past it either.
warp 17.5 400 0
look 0 60
wait 0.4
mark f028-sky
assert height > 390
hook left 0.2
wait 0.6
mark f028-sky-done
# Still up there, still falling under his own gravity and nothing else: no anchor took him.
assert height > 380

# ── ACT 2 · the world fence · SurfaceHoldsNothing ───────────────────────────────────────
# The boulevard `(0, -0.1, -83.75) x (700, 0.3, 27.5)` is a cleared paved strip across the full
# 700 m width, which is what makes this stance possible at all: nothing stands between x = 340
# and the fence's inner face at `350 + fence_margin_m` = **350.18 m**. `look -90` puts the ray
# on +X (same convention as `scripts/f012-edge.txt` act 1), so it reaches the fence 10.18 m out
# — well inside `hook_range_m`, and the fence spans y = -50 .. 200 so a level ray cannot miss
# over or under it.
warp 340 0.05 -83.75
look -90 0
wait 0.5
mark f028-fence
# He is ON the boulevard, INSIDE the map. The act that stood at (400, 0.05, 406) — 50 m outside
# a 700 x 700 m map — exited 0 for a whole day because nothing here asked (`FIND-204`).
assert height > -1
assert height < 1
hook left 0.2
wait 1.0
mark f028-fence-done
# Nothing took him and nothing recovered him: same paving, standing still. Measured 0.050 m and
# 0.000 m/s. The FIND-207 symptom — a hook that anchors on something 134.91 m away and hauls —
# is what a moving player here would mean.
assert height > -1
assert height < 1
assert speed < 1

# ── ACT 3 · THE CONTROL · a titan is not a surface that holds nothing ───────────────────
# ⚠️ Not a miss. This act exists so that the decision `F-029` took stays measured instead of
# remembered: the husk stands 6 m in front on the same boulevard, on the yaw-0 line, and at
# pitch 40 the ray is 5.0 m up when it reaches him — inside his body capsule, and the nearest
# other thing is the boulevard's own edge 13.75 m away where the ray is already 11.5 m up. He
# is the first hit, and he HOLDS: `anchored on body 4003 at 0.35 6.34 -88.55`.
#
# If this act ever reports `SurfaceHoldsNothing` again, `B-007` has reopened and
# `tests/titan.rs::f029_a_rope_bites_a_walking_titan_and_rides_him` is the test that says so.
spawn titan husk 0 0 -89.75
wait 0.6
warp 0 0.05 -83.75
look 0 40
wait 0.4
mark f028-titan
assert height > -1
assert height < 1
hook left 0.2
wait 0.6
mark f028-titan-anchored
assert height > -1
assert height < 1
hook right 0.2
wait 0.8
mark f028-done
end
