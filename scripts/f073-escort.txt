# f073-escort — THE CART GOES HOME, and it stops for the twenty seconds nobody is with it.
#
#   the verdict:  ./target/debug/defeated_by_titan --headless --hub --script scripts/f073-escort.txt --ticks 10500
#   the exit:     ./target/debug/defeated_by_titan --headless --hub --script scripts/f073-escort.txt --ticks 10500 >/dev/null 2>&1; echo $?
#
# ⚠️ The exit code needs its OWN run: a pipeline's `$?` is the LAST command's (`CLAUDE.md`).
# ⚠️ **This run costs about three minutes of wall clock.** A headless tick is a real 1/60 s
# (measured: `f175-loop.txt` does 1153 ticks in 19 s), and an escort is 150 m at 1.2 m/s. There
# is no way to make it cheaper without lying about the mode: the ride IS the mission.
#
# ---------------------------------------------------------------------------------------
# WHAT THIS FILE CLAIMS
#
#   1. the escort door is a door you can WALK to                               (`phase == 2`)
#   2. ⭐ **the mode is finishable in the actual game** — the cart reaches the last waypoint
#      and the sortie is WON, with a real player really staying next to it     (`phase == 3`)
#   3. ⭐ **and it only moves while he is there.** The ride is scheduled for 125.0 s of
#      escorting; a twenty-second gap is cut into the middle of it, and at 133.3 s of elapsed
#      time — by when an unconditional cart would be 10 m PAST its last waypoint — the sortie
#      is still running                                                        (`phase == 2`)
#   4. and it walks the same way home as every other mode              (`phase == 6`, then `5`)
#
# **3 is the one that cannot be faked.** Claim 2 on its own is passed by a cart on a timer, and
# a cart on a timer is not an escort mission — it is a cutscene you are allowed to watch. The
# assert at 130.2 s is what a timer fails.
#
# ---------------------------------------------------------------------------------------
# HOW THE PLAYER FOLLOWS, and why he is twelve metres up
#
# `warp` teleports and zeroes the velocity (`player::apply_warps`), so the follow is a warp to
# the cart's computed position every **0.7 s** — the cart's place at any moment is arithmetic:
# `missions.ron: escort.objective` gives four waypoints, 1.2 m/s and a 12 m escort radius, and
# the cart is only ever where 1.2 m/s × the escorted seconds puts it.
#
# The **12 m of altitude** is not decoration and it is not cheating either:
#
#   * at the warp he is 11.0 m from the cart — inside `escort_radius_m` (12.0), so it rolls;
#   * `game.ron: gravity_m_s2` is −20, so 0.7 s of fall is 4.9 m and he never gets below
#     **y = 7.1** — and `titan.ron: husk.attack_range_m` is **6.0**.
#
# So the one husk `escort.difficulties.recruit` sends at 40 s can chase him the whole way and
# never reach him. Without that the run measures the walking speed of a husk instead of the
# mode: three hits of 34 damage against `game.ron: player.health` 100 is `mission::decide`'s
# second loss path, and the cart would never be the thing that decided this sortie.
#
# ⚠️ **And this is exactly why claim 2 is weaker than it looks.** A player who actually plays
# this mode is on the ground with the titans, and nobody has flown it that way. What is proven
# here is that the CART works, not that the fight around it is any good. UNTUNED.
#
# ⚠️ The cart has no collider: it walks through the buildings on its own path, and so does the
# player who follows it (`missions.ron` says so above the template). That hole is F-073's, not
# this run's.
#
# The phase numbers are `mission::MissionPhase::code`, appended and never inserted:
#   0 Briefing · 1 Deploying · 2 Active · 3 Won · 4 Lost · 5 Hub · 6 Debrief
#
# =========================================================================================
# ACT 1 — the hub, and the one door of the new rank you can actually walk to
# =========================================================================================
#
# `forward = (-sin yaw, 0, -cos yaw)` (`player::locomotion`), so the escort pad at (18, 0, 8)
# is 19.7 m away on bearing **246°** — the mirror of the breach pad's 114°. That one is behind
# the depot hall's east wall and `scripts/f072-breach.txt` holds the repro; this one is out in
# the open, and the walk below is the proof that the second rank of doors is not only reachable
# by teleport (`docs/FINDINGS.md` FIND-162).
#
# ⚠️ `key` only STARTS a hold — the `wait` under it is what spends the seconds.
wait 1.5
assert phase == 5
assert titans == 0
