# f026-marks — the anchor field on screen: *there is an anchor point here.*
#
# `F-026`: *„Alle gueltigen Kandidaten werden als schwache Marker im Sichtfeld eingeblendet."*
# `F-027`: *„Maximal 12 gleichzeitig sichtbare Marker … Marker verblassen mit Distanz und
# werden bei hoher Punktdichte ausgeduennt."*
#
# ⚠️ **THE `Q` / `E` RINGS ARE GONE, 2026-08-26, AND THE FRAMES WERE RETAKEN.**
# `F-026`'s second sentence — *„Die beiden aktuell besten Punkte … tragen das jeweilige
# Tastensymbol"* — was implemented and it was a **lie**: `F-024` is unbuilt, so `Q` fires at
# `vector::aim`'s raycast and not at `AnchorField`'s best candidate, and the two letters named
# two different points. At the stand of leg 1 the fired anchor projected to `(640.00, 357.77)`
# and this element's `Q` ring stood at `(445.93, 352.07)` — **194.15 px, 17.30 deg away**.
# `docs/BUGS.md` B-011 · `docs/FINDINGS.md` FIND-178.
# **The rule: never draw a promise the game does not keep; a disclosed lie is still a lie on
# screen.** The old frames showed two `Q`s and two `E`s and have been replaced.
#
# ## What this file is for
#
# **It is a camera stand, not a proof.** A script cannot see the HUD, so nothing below asserts
# anything about a ring. What it does is hold three stands of very different point density, so
# that three frames of the same element can be read against each other — the sparse one, the
# dense one, and the one where a rope is on a point (`F-026`'s fourth state).
#
# The element's honesty is `tests/hud.rs`, and the script is not one of them:
#   f026_the_drawn_states_differ_in_form_not_only_in_colour
#   f026_every_anchor_mark_stands_on_its_own_projected_pixel        (0.0 px over 12 stand/looks)
#   f026_no_anchor_mark_ever_touches_the_sight_core                 (24 looks)
#   f026_the_field_marks_name_no_key                                (B-011's structural guard)
#   f026_exactly_one_q_and_one_e_are_on_the_screen_and_they_are_the_arms
#   f026_an_anchored_arm_marks_its_rope_with_a_filled_symbol_and_a_tether
#   f027_the_marks_are_capped_thinned_and_stay_far_under_a_seventh_of_the_screen
#   f027_switching_the_markers_off_draws_nothing_and_searches_nothing
#   f030a_the_set_refreshes_at_ten_hertz_and_the_pixel_every_frame
#   f030a_the_candidate_search_stays_inside_its_frame_budget
#
# ## Running it
#
#   cargo build
#   ./target/debug/defeated_by_titan --headless --script scripts/f026-marks.txt --ticks 700 \
#       2>&1 | grep -E 'MARK|assert|script run finished' | tail -20
#   # the exit code needs its OWN run — a pipeline's $? is the last command's:
#   ./target/debug/defeated_by_titan --headless --script scripts/f026-marks.txt \
#       --ticks 700 >/dev/null 2>&1; echo $?
#   # and the frames, one run each (`--ticks` IS the shot tick):
#   ./target/debug/defeated_by_titan --offscreen --script scripts/f026-marks.txt \
#       --ticks 184 --screenshot docs/images/f026-marks-square.png
#   ./target/debug/defeated_by_titan --offscreen --script scripts/f026-marks.txt \
#       --ticks 276 --screenshot docs/images/f026-marks-roofs.png

wait 1.5                       # world, camera, meshes and the render pipelines come up

# ── leg 1 · the market square, looking at the church wall ─────────────────────────────────
#
# Shot at tick 184. `f016-band.txt`'s own stand, chosen there because the wall really carries
# anchors along the crosshair's row — so the rings sit on geometry and not on sky.
warp 51 0 13
look 0 0
wait 1.5
assert height > -0.5
assert height < 0.5
assert speed < 0.5
mark f026-marks-square

# ── leg 2 · high over the district, looking down a street ─────────────────────────────────
#
# Shot at tick 276. The dense case: from up here the cone holds hundreds of roof corners and
# facade rungs, which is what `F-027`'s cap and thinning exist for. If the picture is a wall of
# rings, the cap is not working.
warp 0 60 0
look 35 -25
wait 1.5
assert speed < 60
mark f026-marks-roofs

# ── leg 3 · looking straight up ───────────────────────────────────────────────────────────
#
# Shot at tick 368. The control that costs nothing: nothing is hookable overhead, so the field
# has nothing to draw. A frame with rings in it here is a frame with rings that are not on
# anything.
look 35 85
wait 1.5
mark f026-marks-sky

end
