# F-034 — hit stop: the bodies stop, the clock does not.
#
# cargo run -- --offscreen --script scripts/f034-hitstop.txt --ticks 164 \
#              --screenshot docs/images/f034-hitstop.png
#
# and, as a SEPARATE run, the one that returns a usable exit code:
#
#   cargo run -q -- --headless --script scripts/f034-hitstop.txt --ticks 800
#
# ⚠️ **A `--screenshot` run is not a verdict.** `debug::screenshot::exit_when_written` owns the
# ending and writes `AppExit::Success` the moment the PNG is on disk, without ever reading
# `run.failures` — so the command above exits 0 even when the asserts in this file are RED, and
# the assert summary never prints (`docs/FINDINGS.md` FIND-073). Only the `--headless` run
# reports "N asserts held" and returns an exit code worth reading. Its tick count is
# deliberately generous: overshooting the script's own end is free, undershooting truncates the
# run and hides the summary (FIND-032).
#
# **This is the same run as `scripts/f030-cortex.txt`, photographed six ticks later.** The
# commands below are identical line for line, so the two runs are the same simulation and the
# two PNGs are two ticks out of it:
#
# | tick | image | what it shows |
# |---|---|---|
# | 158 | `docs/images/f030-cortex.png` | the tick the cortex was cut on (tick 157) plus one — the freeze has just begun |
# | 164 | `docs/images/f034-hitstop.png` | six ticks later — the LAST frozen tick |
#
# `gear.ron: feel.hit_stop_cortex_s` is 0.12 s = `round(0.12 x 60)` = **7 ticks**, so the
# player does not advance on ticks 158..164 and moves again on 165. What the pair proves, and
# no single frame can:
#
#   * the husk is visibly further into his dissolve, and the F3 overlay now says so in figures
#     instead of by eye — `husk#1 Death 1/60` in the first image and `husk#1 Death 7/60` in the
#     second, i.e. scaled by `1 - ticks/60` = 0.983 and 0.883: **the clock kept running**;
#   * the player's `pos` is **identical to the digit** — `15.8 7.5 0.8` in both — and `spd 0.0`
#     in both: **the body did not.** Six ticks of world time, zero metres of player.
#
# That is the whole claim of `F-034`, and it is the claim the one-line
# `Time::<Virtual>::set_relative_speed(0.05)` fails — there the tick stops with the body and
# the husk would not have dissolved a millimetre further.
#
# ⚠️ **The freeze is 7 ticks long, and that number did not move on 2026-08-19.** What moved is
# where it sits: the cortex crossing drifted 154 → 157, so the frozen window drifted 155..161 →
# 158..164 and the two `--ticks` above with it. Measured, not assumed — the player's y is 7.468
# on ticks 157, 160 and 163 and 6.756 on 166 (`docs/FINDINGS.md` FIND-112).
#
# ⚠️ `F-034`'s own acceptance in the backlog is a **blind test with human testers**. That is not
# satisfiable by an agent, and **the blind test has not been run.**
#
# ⚠️ **There is no `look` in this file, and adding one back breaks both images at once** — the
# header of `scripts/f030-cortex.txt` explains why, and it is the bug that made both files red.
#
