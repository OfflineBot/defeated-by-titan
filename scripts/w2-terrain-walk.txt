# z = 210 is a street centre (`start_z -333`, lot pitch 42: -294 + 12 * 42 = 210), so the run
# has a lane instead of a row of facades. Walking +X along it from the western rim now rolls
# DOWN the western hollow's floor, then climbs a ~3.9 m rise on foot and drops over its crest
# (walked trace, 2 s samples, `dbt-pinned` 2026-09-02):

#   x -340    -12.05 m   start: the hollow in the west quarter
#   after 10 s  -12.59 m   advancing down the hollow's own floor

#   after 21 s  -12.52 m   MID-CLIMB up the rise at x ~ -205 (its top stands at -9.43)

# The climb from -13.31 to -9.43 between 18 s and 22 s is the evidence B-018 asks for: a body

# ## 🔴 THE CONTROL, because `assert speed` cannot tell walking from standing (B-022)
#
# A leg that goes nowhere still reports `speed 6.000`, and `docs/BUGS.md` B-022 claims outright
# that **no script in this repo can walk a body along X**. So this route was not believed until
# the thing it measures was deleted and the number was watched move (`CLAUDE.md` rule 5).
# Measured 2026-08-29 on the quantised field, same binary, same warp, same 20 s:
#
#   look -90 0  + key W 30    -8.000 -> -5.100 -> -2.250     <- this file (old field's heights)
#   look -90 0  + NO key W    -8.000 -> -8.000 -> -8.000     <- the control: he does not drift
#   look  90 0  + key W 30    -8.500 -> -8.500               <- into the west fence, 10 m away
#   look   0 0  + key W 30    -8.250 -> -7.815               <- a different hillside, along -Z
#   look 180 0  + key W 30   -11.250 -> -11.750              <- and a fourth
#
# Re-run 2026-09-02 on the §5E trimesh: NO `key W` holds -12.051 -> -12.051 -> -12.052 over the
# full 30 s — the same start that walks to -14.322 with `W` held. The walk is the walk.
#
# Four yaws, four different traces, and the run stops dead without `key W`. **On this route the
# +X axis is reachable and the yaw is obeyed**, which contradicts B-022's blanket sentence —
# most likely because B-022 labels `look 90 0` as +X while every script comment in this repo
# (`scripts/f003-map.txt`, `docs/conventions.md`) labels `look -90 0` as +X, so its "+X" leg
# walked into the neighbour it thought it was walking away from. Not fixed here: `src/debug` and
# `src/input` are foreign territory to the terrain round (`docs/FINDINGS.md` FIND-214).

look -90 0                     # yaw -90 = +x (docs/conventions.md)
warp -340 40 210               # over the western hollow; he falls onto it
wait 2.6

mark start
assert height < -11.0          # landed IN the hollow (measured -12.051) and not on a roof
assert height > -13.0          # and on the ground, not through it

key W 30.0                     # walk. No Space, no hook, no boost — legs only.
wait 10.5

mark ten
assert height < -12.2          # BELOW the start (measured -12.590): advancing DOWN the hollow
                               # — without `key W` he holds -12.051 (the control above)
assert height > -13.5          # and still on the ground, not through it

wait 10.0
mark twenty
assert height > -13.4          # measured -12.515: off the -13.31 valley bottom and MID-CLIMB
                               # up the rise at x ~ -205 — climbing, not stopped at its base
assert speed < 12.0            # on foot the whole way

wait 10.0
mark thirty
assert height > -15.0          # on the far side's ground (measured -14.322), not through it
assert height < -13.8          # OVER the rise (its top: -9.43) and down the far side — a
                               # walker stopped at the rise reads -13.3, one on top -9.4

mark end
